# Getting help

1. Read the [README](README.md) and the troubleshooting docs linked from it.
2. Search [existing issues](https://github.com/Iamrushabhshahh/whoop-monitoring/issues?q=is%3Aissue).
3. Still stuck? [Open an issue](https://github.com/Iamrushabhshahh/whoop-monitoring/issues/new/choose) with what you
   ran, what you expected, and what happened (logs help, secrets removed).

This repo covers the WHOOP collector, its dashboards and alerts. Out of scope: WHOOP account, membership or band problems (contact WHOOP), and changes to the WHOOP API itself.

Security problems: do **not** open a public issue. See [SECURITY.md](SECURITY.md).
